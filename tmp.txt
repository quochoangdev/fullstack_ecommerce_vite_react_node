Cách 2: Thiết lập Phím Tắt Tuỳ Chỉnh (Keybinding)
Mở Keyboard Shortcuts bằng cách nhấn Cmd + K Cmd + S.

Nhấp vào biểu tượng Open Keyboard Shortcuts (JSON) ở góc trên phải để chỉnh sửa file keybindings.json.

Thêm đoạn mã sau vào file:

json
Copy code
{
   "key": "cmd+shift+e", // Thay bằng phím bạn muốn dùng
   "command": "editor.action.insertSnippet",
   "args": {
      "snippet": "// ---------- end add cart ----------"
   }
}
Lưu file. Từ giờ, bạn có thể dùng Cmd + Shift + E (hoặc phím bạn đã chọn) để chèn comment theo yêu cầu.
